# 巡安使用体验优化 · 2026-10-23

本轮保留工作台原有深色侧栏、青绿色按钮和卡片布局，重点改进首次上手、查找证据、复查和报告交付。

## 怎么体验

在仓库目录启动 `python3 -m xunan`，打开 `http://127.0.0.1:8765`。

1. 首次进入可查看三步引导，也可从工作台点击“使用引导”重看。
2. 点击“开始样例演示”，填写需要的测试关键词，确认授权，运行修复前样例。
3. 在“风险与证据”选择级别、确认状态；展开“更多筛选”，可同时按规则、分类、页面和标题/脱敏证据查找。可以切换时间排序或一键清除筛选。
4. 查看一条证据，复制已脱敏内容，填写人工复核意见并保存。复制权限被拒绝时会提示手动选取。
5. 点击“下一步：检查修复版”，会自动选中同一演示基线。当前会话刚提交的关键词会带入；历史记录未保存关键词原文，需要自行核对。再次确认授权后查看四类对比结果。
6. 打开“报告中心”，先预览报告及完整 JSON，再下载需要的格式。

## 已完成

- 历史记录：目标/日期/编号搜索、演示与网站分类、每页 10 条分页；范围为服务端最近 100 条记录。
- 基线选择：按检查方式和规范化后的目标地址过滤；演示允许修复前后对比。后端原有校验继续生效。
- 记录标签：完整年份、样例版本、发现数量、是否有基线和编号。
- 风险：多条件筛选、级别/时间排序、筛选无结果时的一键恢复、中文分类名称。
- 弹窗：键盘焦点限制在弹窗中、关闭后尽量回到原按钮、复制反馈和加载骨架。
- 等待状态：显示真实等待秒数，暂时锁定巡检参数，阻止重复提交，离开页面时提示。
- 报告：基于服务返回的 JSON 安全构建站内阅读预览；JSON 可整体展开。预览失败可重试。CSV 增加复核备注；HTML/Markdown 增加中文对比明细和复核备注。
- 定时计划：创建时可填写关键词；支持启用/停用和查看上次结果。仍由现有后端负责校验与执行。
- 自动同步：可见页面每 20 秒刷新，后台标签、弹窗打开及手动巡检期间暂停；保留正在填写的输入。
- 运行信息：展示版本、服务提供的恒脑配置说明、私网开关、目标和事件数量；该说明不代表恒脑实时连通性检测。
- 手机界面：记录和风险表格改为纵向卡片；所有主要按钮有可访问名称。减少动态效果的系统偏好会关闭骨架动画。

## 本轮边界

后台仍使用同步巡检接口，没有新增后台任务队列、逐页进度或取消接口。界面显示等待时间，不展示未经后台提供的进度百分比。也没有新增记录删除/归档、关键词模板、任意两次对比或演示数据重置。

本轮修改的是 `web/` 中的巡检工作台。GitHub Pages 现有流程部署的是 `demo-target/` 静态介绍与样例页；运行这些新增操作需要启动 Python 后端。恒脑正式工作流的长期 HTTPS 部署仍按原计划推进。
