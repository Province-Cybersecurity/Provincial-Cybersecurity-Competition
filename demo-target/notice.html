这是巡安团队自建的公开静态页面，专门用于比赛中的授权巡检演示。页面内所有“敏感信息”都是虚构测试数据。

授权状态允许本项目的巡安服务进行只读检查
01

这个页面用来做什么？

当巡安读取本站时，应该能发现预先放置的邮箱、内部标记和虚构令牌，并生成带有脱敏证据的检查结果。团队可以用它验证从“发现页面”到“输出报告”的完整流程。

02

页面里有哪些测试数据？

邮箱格式training-contact@example.invalid虚构
内部标记DEMO_INTERNAL_ONLY虚构
令牌格式DEMO_ONLY_NOT_A_REAL_TOKEN_123456虚构
03

授权范围是什么？

授权范围只包含本团队 GitHub Pages 下的演示页面和静态文件。巡检只允许读取公开资源，不允许把 GitHub 平台、其他仓库、外部链接或任何第三方网站当作测试目标。

04

怎样正确使用？

  1. 将本页面的完整网址加入巡安后端的目标允许列表。
  2. 通过恒脑智能体或巡安管理页面发起一次只读检查。
  3. 确认报告中的证据已经脱敏，并与上方样例相符。
  4. 演示结束后保留报告，作为作品联调和答辩材料。
